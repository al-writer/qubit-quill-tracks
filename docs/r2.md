# Настройка Cloudflare R2

R2 — хранилище для всего тяжёлого: песни, футаж, куски рендера и готовые
видео. В git остаются только код, `project.json` и `build/*.json`. Исходящий
трафик из R2 бесплатный, а бесплатного объёма (10 ГБ хранения и
миллионы операций в месяц) хватает на эту работу: куски рендера удаляются
сразу после склейки.

Займёт около 10 минут.

## 1. Включить R2

1. Зайдите (или зарегистрируйтесь) на <https://dash.cloudflare.com>.
2. В меню слева откройте **R2 Object Storage**.
3. Нажмите кнопку подключения R2. Cloudflare попросит привязать карту:
   без неё R2 не включается, хотя в пределах бесплатного лимита списаний нет.

## 2. Создать бакет

1. **R2 Object Storage → Create bucket**.
2. Имя, например `qubit-quill`. Location: Automatic. Storage class: Standard.
3. Публичный доступ **не** включайте: workflows работают по ключам, а
   скачивать видео можно по временным ссылкам из сводки запуска.

## 3. Правило автоудаления (страховка)

Workflows сами удаляют куски рендера, даже если рендер упал. Правило — на
случай, если отменить запуск посреди работы.

1. Откройте бакет → **Settings → Object lifecycle rules → Add rule**.
2. Name: `chunks`, prefix: `runs/`, action: **Delete objects** after **1 day**.
3. (По желанию) второе правило для `renders/`, если не хотите хранить готовые
   видео в R2 дольше, например 30 дней: они остаются в черновиках релизов.

## 4. Ключ доступа

1. **R2 Object Storage → Manage API tokens → Create API token**
   (подойдёт Account API token).
2. Permissions: **Object Read & Write**.
3. Specify bucket(s): только ваш бакет (`qubit-quill`).
4. Create. Скопируйте **Access Key ID** и **Secret Access Key**: секрет
   показывается один раз.
5. **Account ID** указан на главной странице R2 (справа, *Account details*)
   или в адресе страницы `dash.cloudflare.com/<account id>/r2`.

## 5. Секреты в GitHub

В репозитории **qubit-quill-tracks**: Settings → Secrets and variables →
Actions → **New repository secret**, четыре раза:

| имя | значение |
| --- | --- |
| `R2_ACCOUNT_ID` | Account ID |
| `R2_ACCESS_KEY_ID` | Access Key ID |
| `R2_SECRET_ACCESS_KEY` | Secret Access Key |
| `R2_BUCKET` | имя бакета, например `qubit-quill` |

## 6. Перенести песни в R2

Сейчас песни скачиваются по ссылкам из истории репозитория студии. Чтобы
перенести их (и футаж будущих треков) в R2:

Actions → **Move media to R2** → Run workflow (поле *track* пустое = все
треки). Workflow загрузит файлы в `projects/<slug>/…`, пропишет в
`project.json` ссылки `r2://…` и закоммитит. Контрольная сумма файла та же,
поэтому треки заново не готовятся.

То же локально (нужен клон студии рядом):

```sh
export R2_ACCOUNT_ID=… R2_BUCKET=… AWS_ACCESS_KEY_ID=… AWS_SECRET_ACCESS_KEY=…
node ../lyric-motion-studio/tools/media.mjs migrate --projects tracks --all
# или один файл:
node ../lyric-motion-studio/tools/media.mjs push --projects tracks --track my-song --file ~/Music/my-song.flac
```

## Что где лежит в бакете

| префикс | что | сколько живёт |
| --- | --- | --- |
| `projects/<slug>/` | песни и футаж | пока не удалите |
| `runs/<run id>/` | куски рендера | удаляются после склейки (и правилом через сутки) |
| `renders/<slug>/<run id>/` | готовые видео | пока не удалите (или правилом) |

Ссылка на скачивание видео на 7 дней появляется в сводке запуска *Render
video*. Видео также попадают в черновик релиза, если они меньше 2 ГБ
(ограничение GitHub).
